# QA - Casos de Teste - Service Desk

Repositório de casos de teste manuais para sistema de chamados (GLPI / Jira-like)

**Autor:** Eduardo Mendonça - Técnico Suporte N1/N2 | Engenharia de Software UNIFACS - Salvador/BA  
**GitHub:** @Eduardomendoncacl  
**Ferramentas:** Jira, GLPI, Test Cases, Bug Report, ITIL, SLA

## Objetivo
Demonstrar criação de casos de teste, execução e documentação de bugs seguindo boas práticas de QA para vagas de Suporte Jr e QA Jr.

## Estrutura
- `/casos-de-teste` - Casos de teste funcionais
- `/bug-reports` - Relatórios de bugs com evidências

## Como executar
Todos os casos estão com pré-condições e resultados esperados para execução manual.
